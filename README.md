# Keyless-Electronic-Door-Lock
This is a group project that I worked on in an Intro to Engineering class in Fall 2025. The project consists of an Arduino Mega board, breadboard, RFID reader, number keypad, LCD display, servo motor, and a door lock. The project allows for a door lock to be opened without a key by using a password on the keypad or a rfid card with a recongnized id.

In addition to this I have a demonstration video of the project in action: https://www.youtube.com/watch?v=QHXwPzO9o_8

On this page I have screenshots of images of the project in different stages of development.

The project is a small scale done in order to allow for me and my fellow group members to establish hands on and planning skills neccessary for the engineering industry. 

My work on the project involved planning and assemblying the component layout/wiring. I also did a majority of the coding for the project with Arduino IDE. I have some previous experience with coding in Arduino IDE with my own personal microcontroller.

Now that this project is concluded, I think it's given me a better understanding of circuit layout, prototyping on breadboards, functions of electronic components, C++, soldering, as well as other skills that will make me a better electrical engineer in the future.
